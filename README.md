# Stellar

A React-based web application showcasing live Earth streams, a solar system visualization, and AI-powered features.

## Features
- Live Earth stream via embedded iframes
- 3D Solar System visualization using Three.js
- Interactive chatbot with AI integration
- Timeline of space events
- Responsive design with Tailwind CSS

## Technologies
- React 19
- Three.js & @react-three/fiber
- Tailwind CSS
- Axios for API requests
- Framer Motion for animations
